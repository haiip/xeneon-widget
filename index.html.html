Xeneon Edge — Spotify och Discord

Gör de här stegen en gång i en vanlig webbläsare. Resultatet blir en URL som du klistrar in i iCUE:s iFrame-widget. Inget skickas någonstans — allt sparas lokalt i din webbläsare.

1. Skapa en Spotify-app

Gå till developer.spotify.com/dashboard → Create app. Sätt Redirect URI till exakt den här sidans adress:

Kryssa i Web API, spara, och kopiera Client ID hit.

2. Slå på Discords server-widget

I Discord: Serverinställningar → Widget → slå på Enable server widget. Kopiera server-ID:t (aktivera utvecklarläge, högerklicka på servern → Kopiera server-ID).

Widgeten visar vilka som är online och vilka röstkanaler som är igång. Textchatten går inte att bädda in — Discord tillåter inte det.

3. Tillbaka till musiken automatiskt

Antal sekunder innan Discord-vyn växlar tillbaka till Spotify av sig själv. Skriv 0 för att stänga av.

4. Klistra in i iCUE

Din widget-adress. Lägg till en iFrame-widget på Xeneon Edge-panelen i iCUE och klistra in den här.

Logga in på Spotify först.

Adressen innehåller din personliga token. Behåll den för dig själv.
