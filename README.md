# Xeneon Edge — Personal Dashboard (Spotify, Discord & Deadlock)

An unofficial, non-commercial fan-made dashboard designed as an iFrame widget for the Corsair XENEON EDGE display via iCUE. This project is built strictly for personal use and learning purposes.
